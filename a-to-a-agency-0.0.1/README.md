# A to A Agency 0.0.1

Production-ready starter landing app for a public agency command-center experience.

## Tech

- Next.js (App Router)
- TypeScript
- Tailwind CSS

## Run locally

```bash
cd a-to-a-agency-0.0.1
npm install
npm run dev
```

Open: `http://localhost:3000`.

## Deploy

This folder is Vercel-ready as-is.

1. Import the folder into a Vercel project.
2. Framework preset: `Next.js`.
3. Install command: `npm install`.
4. Build command: `npm run build`.

## Notes

- Dashboard metrics and contact email are placeholder/illustrative content.
- Replace all placeholder data and contact channels before production.
- No real client data, income guarantees, policy quotes, carrier claims, or licensed-agent advice are included.
