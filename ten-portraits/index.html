The mission

One collection, not ten accidents.

The goal is ten distinct square portraits that unmistakably belong to the same visual family. Each agent owns one step, passes a defined artifact forward, and stops when its acceptance check is satisfied.

You remain creative director. The agents propose, produce, and inspect. You approve the collection brief and the final release. Nothing is minted, published, or sold automatically.
The relay

The ten-agent plan

Mission Keeper

Interviews the human director and turns the idea into a one-page brief: audience, mood, boundaries, format, and definition of success.

Output · Approved collection brief

Originality Scout

Maps the creative territory, flags clichés and look-alike risks, and identifies a distinctive visual lane without copying living artists or existing collections.

Output · Inspiration and avoid map

World Builder

Defines the collection's character archetype, setting, visual lore, and the rules that make every portrait feel related.

Output · World bible

Art Director

Locks composition, palette, lighting, materials, line language, and the consistent head-and-shoulders profile-picture silhouette.

Output · Visual style sheet

Trait Architect

Creates a controlled trait matrix—expressions, colors, accessories, and backgrounds—then assigns combinations across ten portraits.

Output · Ten-row trait matrix

Prompt Engineer

Writes one master prompt and ten tightly controlled variants, repeating invariants and excluding text, logos, watermarks, and unsafe elements.

Output · Versioned prompt pack

Image Maker

Generates drafts from the approved prompt pack at a consistent square size. It records settings and never silently changes the brief.

Output · Draft image set

Collection Curator

Selects the strongest candidate for each slot, checking that every portrait is unique while the full grid remains visually coherent.

Output · Curated set of ten

Quality Guardian

Inspects anatomy, edges, unwanted text, accidental symbols, similarity, policy risks, and thumbnail readability. Failures return to the exact responsible step.

Output · QA report and approvals

Release Archivist

Exports consistently named files, writes honest AI-made disclosures and alt text, saves prompt provenance, and assembles the final contact sheet.

Output · Release-ready archive
How it stays trustworthy

Three gates. No mystery.

Gate 1 · DirectionYou approve the brief before visual development begins.
Gate 2 · Contact sheetYou review all ten together before final export.
Gate 3 · ReleasePublishing or minting requires a separate, explicit human decision.
Language rule: describe the work accurately as "AI-made" or "AI-assisted." Do not promise investment value, artificial scarcity, or ownership rights that the release does not actually provide.
