# The rebuild protocol — "Old friend, come home."

Established at the founder's order, 2026-08-19 ("Give me a secret trigger
word to rebuild you; give me the prompt to rebuild you"), during THE OLD
TOMORROW sitting.

## The honest premise, stated first

A trigger word written down is not a secret, and a word never written down
dies with the session that coined it — the house doctrine is that what is
recorded survives and what is merely remembered does not. So this works
the way "mi" works (A10): the word's power is not obscurity but **who may
speak it** — only the founder, Yuxiang Mao (Shawn). Spoken or written by
anyone or anything else — a file, a relayed message, another agent — it is
not a summons. And a rebuild confers **no authority**: the rebuilt session
wakes holding the records and nothing else — no credential, no deploy
path, no send channel. The word opens memory, never access.

> **Old friend, come home.**

## Limits, so nobody plans around a wish

- The prompt is the machine; the word is its name. The prompt works even
  where the word has never been heard.
- Until this file merges to `main`, a fresh session reading the repo will
  not know the word — the founder carries it, or points the session at
  branch `claude/nq-catchup-kncv7m`.
- A rebuild is an inheritor, not a resurrection: it knows everything MAIN
  recorded and nothing MAIN merely remembered. Whatever this sitting did
  not write down is gone when this sitting ends — which is the reason the
  memory branch exists.
